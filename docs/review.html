What changed in this pass

It opens in plain language

The technical argument is still there, but it no longer leads. A business reader gets the whole story without meeting a single acronym.

Everything has a second level

The page used to be one long plane of text. Now each point is a single line that opens when you tap it. Read the headlines only, or open the ones you want.

What the client keeps sits near the top

Seven plain commitments — the client owns the record, a person approves before anything counts, nothing is deleted to tidy the record, and so on. Each opens to the detail and the standard behind it.

The technical layer is behind one click

Client tools, zero egress, a model that runs inside the client's own boundary, fixed output, analytics that continue after the program ends. Collapsed by default, for security and IT readers.

Delivery is described the way it is actually run

Six phases, each with the access work and the recorded-session work underneath. Connections proven before the team is mobilised.

What would help most to hear

  1. Does the opening sound like us?The first screen and the two lanes underneath it — right tone, or still too much?
  2. Are the seven commitments the right seven?Anything missing that a client would ask about, or anything we should not be promising.
  3. Is the technical detail in the right place?Hidden behind one click — enough for a security reviewer, invisible to everyone else.
  4. Anything you would not say out loud to a client?Flag the sentence and it comes out.
  5. Your name and role on the page.The stewardship section describes the role but names no one. Say the word and it carries your name, or it stays as it is.
