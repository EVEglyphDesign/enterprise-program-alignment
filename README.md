This surface uses the **green executive-safety-briefing template** (source: `ai-program-alignment.html`, attached by Dany). Palette: warm paper neutrals with one security-green accent (`#0d6756`). ## How to publish

Any static host works. Recommended options:

- **GitHub Pages** — commit the folder to a public repository, enable Pages on `main`, and the file becomes `https://<org>.github.io/<repo>/enterprise-program-alignment.html`. See the `publish-to-github-pages` skill for the zero-gate flow.
- **Cloudflare Pages / Netlify / Vercel** — drop-in static deployment; no configuration required.
